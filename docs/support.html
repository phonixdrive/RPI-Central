Support

Let’s narrow it down.

RPI Central is an active development project. Reproducible reports with the affected semester and screen are the most useful.

Before reporting a problem

  • Confirm you are using the latest build.
  • Check the selected current term and “Started college” setting.
  • Allow a loading indicator to finish, but note that the app should remain interactive.
  • For social or cloud features, confirm that you are signed in and online.
  • Never include access tokens, private messages, or personal calendar details in a public issue.

Common checks

Course room or instructor is stale

Open the Courses tab while online/in the latest bundled build. Current-term enrollments should refresh without removing and re-adding the class.

A chat repeatedly says New

Open the thread, return to Chat, and note whether another account actually sent a newer message. Include the chat type—DM, friend group, or class group—in the report.

Dashboard layout resets

Reorder cards, leave edit mode, background and reopen the app. Report whether the issue follows a normal relaunch, an Xcode stop, or a full uninstall; uninstalling removes local app storage.
