Privacy overview

Your data should serve you.

This page describes the current open-source development build. It is a project overview, not a substitute for an App Store privacy label or a formal legal policy.

Data kept on the device

Course selections, personal events, grades, notes, GPA overrides, tasks, dashboard settings, meal-plan state, Flex Dollars planning, study-timer preferences, and imported calendar state are primarily stored locally.

Calendar access

RPI Central requests calendar permission only when you choose calendar import or sync features. Google and Outlook calendar access is mediated by accounts configured in Apple Calendar through EventKit.

Firebase and social features

When you sign in or use Social, Firebase may store profile information, friendships, requests, group membership, messages, shared schedules, device notification tokens, and cloud backup snapshots. Access is restricted by Firestore security rules maintained in the repository.

Schedule sharing

Schedule sharing is optional and intended for accepted friends. The app can show a friend’s current calendar activity only when that friend has enabled sharing.

Location

The shuttle map displays shuttle information. Live person-location sharing is not implemented. The app should not be represented as tracking students.

Retention and deletion

Local data can be removed by clearing app entries or deleting the app. Cloud data and backups require authenticated deletion support in the relevant Firebase environment. Do not use production personal data in development environments.

Questions

For a privacy concern, use the project’s support guidance. Report security vulnerabilities privately through GitHub Security Advisories.
