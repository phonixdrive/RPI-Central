2.4 · Fall 2026 development

  • Fall 2026 became the current term, with refreshed semester data.
  • The 2026–2027 academic calendar and Thanksgiving break were added.

  • Direct messages, friend activity, compact chat timestamps, and improved unread handling were added.
  • Google/Outlook calendar import and weekly cloud recovery backups were added.
